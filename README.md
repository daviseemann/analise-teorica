# Análise Teórica - Dados Sintéticos Gaussianas

Projeto minimalista para estudo de distribuições gaussianas com dados sintéticos.

## Estrutura

```
├── data/              # Dados sintéticos gerados
├── notebooks/         # Análises em Jupyter
├── src/               # Utilitários reutilizáveis
└── requirements.txt   # Dependências
```

## Quick Start

```bash
pip install -r requirements.txt
jupyter notebook
```
